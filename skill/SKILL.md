# DSH 会话与轮次深层直达指南

本 Skill 指导 Agent 如何在 DeepSeek Harness (DSH) 环境中为用户提供**可点击直达的高性能深层链接（Deep Link）**。

## 1. 适用场景

- 用户询问：“帮我找找之前讨论过某个话题的会话”；
- 用户在方案推敲中需要追溯历史对话：“我们在哪次会话里定了这个规则？第几轮？”；
- 用户希望在不中断当前聊天窗口的前提下，在新独立窗口中打开历史会话并跳到指定位置。

## 2. 检索定位方法

你可以通过执行轻量 Python/Node 查询本机 `~/.dsh/storages/sessions-fts.db`，快速获取目标会话的 `sessionId` 与目标轮次编号 `turnIndex`（1-based，即第几个 `user/message`）：

```bash
python3 -c "
import sqlite3, os
db = sqlite3.connect(os.path.expanduser('~/.dsh/storages/sessions-fts.db'))
# 查找匹配的会话与轮次
"
```

## 3. 输出格式规范（触发前端胶囊与新窗口弹出）

在回复用户时，必须使用以下标准格式输出直达链接：

```markdown
[查看会话：<会话名称/核心主题> · 第 <N> 轮 ↗](http://127.0.0.1:3080/?session=<sessionId>&turn=<N>)
```

### 输出示例：
> 针对你的改稿安全诉求，我们在之前的会话中进行了深度推敲：
> - 🔗 [查看会话：@skill使用范例 你发现了没有？ · 第 1 轮 ↗](http://127.0.0.1:3080/?session=session-75271ba9-0162-4071-950e-28c4f96fc35f&turn=1)  
>   *摘要：确认了当任务存在剪辑稿时，必须先出方案征求用户同意，禁止直接静默覆盖。*
> - 🔗 [查看会话：@skill使用范例 你发现了没有？ · 第 2 轮 ↗](http://127.0.0.1:3080/?session=session-75271ba9-0162-4071-950e-28c4f96fc35f&turn=2)  
>   *摘要：确立了底层自动保存 10 个历史版本快照并在桌面端提供一键恢复菜单的安全机制。*

## 4. 前端交互效果说明

- 安装了 `dsh-session-navigator` 插件的前端会将此链接自动渲染为**带有 🧭 图标的高亮胶囊按钮**；
- 用户点击后，**绝不会冲掉当前正在聊天的窗口**，而是直接弹出一个尺寸适中的独立窗口；
- 新窗口打开后会自动选中该会话，并平滑滚动定位到第 `<N>` 轮，辅以柔和的光晕高亮动画提示。
